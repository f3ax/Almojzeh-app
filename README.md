# المعجزة لمكافحة الحشرات - Al-Mojza Pest Control

Demo web application for a pest control company in Jordan. Arabic-first with English toggle, optimized for mobile browsers.

## Quick Start

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

## Tech Stack

- Vite + React
- Tailwind CSS (RTL support)
- react-i18next (Arabic/English)
- JsBarcode + html5-qrcode (barcode generation/scanning)
- jsPDF (PDF report generation)
- Recharts (dashboard charts)
- localStorage (demo database)
